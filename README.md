## 🔍 Overview

Given a brain MRI scan, this model answers two questions in a single forward pass:

1. **Is there a tumor?**
2. **If yes — what type?**
   - Glioma
   - Meningioma
   - Pituitary tumor

Scans with no abnormality are labeled **No Tumor**.

This is implemented as one unified 4-class CNN (`glioma`, `meningioma`, `pituitary`, `notumor`) trained on the [Brain Tumor MRI Dataset](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset), achieving **~96% test accuracy**.

## ⚙️ How It Works

```
MRI Scan → Preprocessing & Augmentation → CNN → Softmax (4 classes)
                                                    │
                                    ┌───────────────┼───────────────┐
                                notumor          glioma      meningioma / pituitary
                              (no tumor)      (tumor type)     (tumor type)
```

## 🏗️ Model Architecture

| Layer | Details |
|---|---|
| Conv2D + MaxPooling | 32 filters, 3×3, ReLU |
| Conv2D + MaxPooling | 64 filters, 3×3, ReLU |
| Conv2D + MaxPooling | 128 filters, 3×3, ReLU |
| Conv2D + MaxPooling | 128 filters, 3×3, ReLU |
| Flatten | — |
| Dense | 512 units, ReLU |
| Dropout | 0.5 |
| Dense (Output) | 4 units, Softmax |

**Training config:** image size `150×150`, batch size `32`, `25` epochs, Adam optimizer, categorical cross-entropy loss, with data augmentation (rotation, shift, shear, zoom, flips).

## 📊 Results

| Metric | Value |

| Test Accuracy | ~96% |
