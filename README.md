## 🔍 Overview

Given a brain MRI scan, this project implements a structured diagnostic pipeline divided into **two distinct classification stages**:

1. **Stage 1 (Binary Classification):** Determines whether the brain MRI scan is healthy (**No Tumor**) or contains an abnormality (**Tumor**) using a binary screening filter with a sigmoid activation and binary crossentropy loss.
2. **Stage 2 (Multi-class Classification):** If a tumor is detected, it further categorizes the specific type into one of three major classes: **Glioma**, **Meningioma**, or **Pituitary tumor** using a softmax activation and categorical crossentropy loss.

Independent test accuracy on unseen MRI scans reaches **91%** through this two-stage screening and typing design.

## 🏗️ Model Architecture

| Layer | Details |
|---|---|
| Conv2D + MaxPooling | 32 filters, 3×3, ReLU |
| Conv2D + MaxPooling | 64 filters, 3×3, ReLU |
| Conv2D + MaxPooling | 128 filters, 3×3, ReLU |
| Conv2D + MaxPooling | 128 filters, 3×3, ReLU |
| Flatten | — |
| Dense | 512 units, ReLU |
| Dropout | 0.5 |
| Output Head | **Stage 1:** Dense(1, sigmoid)<br>**Stage 2:** Dense(3, softmax) |

**Training config:** image size `150×150×3`, batch size `32`, `50` epochs, Adam optimizer, with real-time data augmentation (rotation ±20°, width/height shift 10%, shear 10%, zoom 10%, and dual-axis flipping).
